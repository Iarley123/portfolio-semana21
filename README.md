# Portfólio profissional — Semana 21

## Como visualizar
1. Abra o arquivo `index.html` no navegador.
2. Para editar, abra o arquivo em um editor de código, como VS Code.

## Objetivo
Wireframe/primeira versão visual de um portfólio profissional, com seções de início, sobre, projetos, habilidades e contato.

## Personalização rápida
- Troque `seuemail@exemplo.com` pelo seu e-mail, se quiser.
- Atualize os projetos e habilidades para refletir o que você realmente desenvolveu.
- O projeto usa HTML, CSS e JavaScript no mesmo arquivo para facilitar a entrega inicial.
